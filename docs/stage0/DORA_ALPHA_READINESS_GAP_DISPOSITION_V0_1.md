## Decision and boundaries

This is the versioned 6.2 evidence-applicability and mandatory-gap decision authorized by the Project Owner task. It consumes frozen 6.1 and applies the frozen GAPS criteria without changing their text. No legal/privacy/security approval or runtime acceptance is asserted.

Each gap has exactly one disposition. blocking identifies the exact future boundary named in its deadline; blocks_6_3 independently identifies minimum admission predecessors. An accepted reusable-evidence row does not discharge separately listed product integration obligations.

Implementation and acceptance are separate. Before affected code: approve exact design/data/artifact/protocol prerequisites stated per row. During implementation acceptance: prove actual behavior on the actual build. All implementation still waits for 6.3; no downstream task is started here. This is an explicit prospective first-Alpha sequencing overlay on the older broad readiness/Technical Plan Stage 0-before-production language, not a retrospective full-MVP PoC waiver.

Capture exploratory evidence is enough to begin the bounded Stage 8 path only after 6.3 and GAP-CAP-02/GAP-REC-02 pre-code requirements. Clean 3600-s screen-off and POCO/OEM proof are mandatory at 8.6, not before coding. No 8-hour stability, all-OEM or production capture claim is made.

Search supports a bounded lexical implementation path after 6.3 and exact product dependency/schema/protocol admission. The actual 10.2/10.3C build must pass correctness, 10k/1M latency and storage/update predicates. SEARCH_V2 is prospective Stage 0 evidence only; the Alpha protocol must bind its predicates or an explicit prospective replacement before measurement. No blanket Stage 0C rerun and no automatic FTS4 production admission.

Energy comparator mechanics do not prove energy. Capture-first/no-concurrent-heavy-ML remains the safe default until applicable evidence. Freeze scheduling and measurement/aggregation/trace decisions before affected implementation/measurement; physical capture/VAD energy and thermal evidence is required at 8.6, integrated workloads by 12.1 before 12.4. Unknown mWh/aggregation/fallback cannot become PASS.
