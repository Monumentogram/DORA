Дата: 29 октября 2026 года. Ветка: `codex/stage10-signal-ui`.

**PASS / SIGNAL_UI_ALPHA_READY** — реализация, локальные проверки и подписанная APK.
**DEVICE_VALIDATION_PENDING** — новая APK на POCO не устанавливалась.
Статус CI опубликованной ветки проверяется отдельно от локальных результатов ниже.

## Реализация

- Главная: реальные зашифрованные записи, постраничная загрузка, название из активного
  текста или короткого идентификатора, длительность, фрагмент, статус, дата расшифровки,
  пустое состояние и повтор загрузки. Кнопка новой записи и навигация к настройкам.
- Запись: существующие согласие, микрофон, таймер, пауза, продолжение, подтверждение
  завершения и состояние сохранения; горизонтальная история уровня сигнала.
- Отдельная запись: заголовок и дата расшифровки, исходный аудиоплеер, прогресс,
  перемотка, редактирование, подтверждение закрытия черновика, история и повторное ASR.
- Настройки: Whisper, языки RU/EN, проверка и импорт модели, существующее подключение
  Cloud, безопасность и сведения о приложении. Отправка аудио требует прежнего согласия.
- Общая система: светлая/тёмная темы с синим акцентом, семантические цвета,
  крупные элементы управления, системный размер текста и английские ресурсы.

База — `a6130cfcb4c95cbc101c1d35f019419aa479a653`, ветка
`stage/9.3-permanent-cloud-access`. Owner-local итоговый отчёт Stage 9.3 подтверждает
готовность постоянного Local/Cloud доступа и разрешает переход к Signal; его статус
обновляет более ранний публикационный снимок отчёта в исходниках.
PR #119 и другие незавершённые PR не сливались. Решения: DEC-051 и ADR-SIGNAL-002.

Native-сценарий дважды распознаёт зашифрованный оригинал, сохраняет ручные правки и
версии, проверяет выбор активной версии, повторное открытие хранилища и отмену.
Использована прежняя модель Small q8_0 с проверенным SHA-256
`49c8fb02b65e6049d5fa6c04f81f53b867b5ec9540406812c643f177317f779f`.
Эмулятор x86_64 с размером страницы 4096; это отдельный debug runtime,
а в итоговой APK сохранён прежний arm64 runtime.

UI-проверки подтверждают сохранение аудио, редактирование и повторное открытие текста,
неизменность ссылки на оригинал после правок, воспроизведение, перемотку и остановку
при фоне или занятости редактора. Данные тестового приложения сохранялись при
обновлениях через `adb install -r`; очистка данных и переустановка не выполнялись.
Проверки с отсутствующей моделью выполнялись отдельно от реального native ASR.

Независимое ревью обнаружило конфликт открытия сессии плеером во время операции
редактора. Добавлены запрет запуска и остановка при busy; регрессия покрыта тестом.
Гонка с автоматической загрузкой библиотеки в подготовке тестовых данных устранена
изоляцией тестовой сессии. Проверка скриншота больше не ждёт невидимую строку LazyColumn
при крупном шрифте. После освобождения диска и ограничения памяти сборки прошли.

## Ограничения и оставшаяся проверка

- POCO: DEVICE_VALIDATION_PENDING. Установки, сброса, миграции данных и merge не было.
- Живой Cloud round trip из новой APK не повторялся: проверены backend contracts,
  Android unit contracts и существующие UI-пути; действующий backend не изменялся.
- Схема не хранит пользовательское название и дату начала записи. Отображаются
  производное название и явно обозначенная дата расшифровки; дата записи не выдумана.
- Поиск отсутствует, поскольку соответствующего механизма в baseline нет.
- Сохранена граница Alpha в 5 минут. Несохранённые правки очищаются при уходе в фон
  согласно прежнему поведению; подтверждение действует для Back/Close внутри редактора.
- Некоторые унаследованные диагностические/восстановительные сообщения остаются RU.
- Производительность оценена в основных UI-сценариях; отдельный benchmark POCO не проведён.
