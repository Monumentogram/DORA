No metadata, semantic commit, processing intent or other durable meaning is adopted from bytes that are unauthenticated. The unauthenticated or corrupt remainder is rejected and routed to bounded quarantine. The unchanged relation is `0 <= C <= R <= A`; every returned byte is authenticated; the 8,160-byte / 0.255-second design bound remains unchanged.\

Source and fault boundary: physical-source extent means only bounded observed candidate bytes under the future harness policy. This decision does not trust arbitrary post-crash append data. For `TRU-03`, “prefix unchanged” means that recovered prefix byte values and their authentication remain unchanged; it does not require an identical recovered endpoint when an independently authenticated pre-existing tail becomes readable. A same-file suffix cannot silently promote a whole object.\

Architecture and testing effects: streaming implementation is eligible only as an exact separately scoped synthetic, non-metric Stage 0 slice under `OD-15`. Persistence schema, quarantine mechanics, source-extent enforcement, typed diagnostics and any durability behavior require a later accepted ADR and implementation scope.
