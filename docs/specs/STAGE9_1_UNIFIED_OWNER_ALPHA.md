# DORA — Stage 9.1: Unified Owner Alpha — Local + Cloud

## 1. Главная цель

Собрать, установить и проверить единую актуальную Alpha APK DORA с двумя полноценными способами распознавания речи:

- **Local ASR:** Whisper SMALL q8, полностью офлайн, без календарного ограничения.
- **Cloud ASR:** Amazon Transcribe Batch, подключение через HTTPS, с явным согласием пользователя.

Оба механизма должны работать с одними и теми же записями, сохраняя независимые версии расшифровок и ручные правки.

Дополнительная цель — обеспечить прямое подключение POCO M5 к AWS без USB-туннеля.

**Приоритет: получить работающую пользовательскую Alpha как можно быстрее.**

Не выполнять масштабный рефакторинг, новые исследования качества ASR и нагрузочные испытания Recovery.

## 4. Подготовить одну устанавливаемую APK

Собрать новую owner-only Alpha APK.

Обязательные требования:

- Тот же `applicationId`, что у установленной версии.
- Та же оригинальная подпись.
- Корректный versionCode для обновления.
- Поддержка Android 14 / API 34.
- Поддержка arm64-v8a.
- Сохранение зашифрованных данных.
- Отсутствие необходимости переустановки приложения с удалением данных.
- Совместимость с существующим Whisper model store.

Предварительно проверить совместимость форматов и схем хранения.

Выполнить тесты обновления на копии данных либо безопасном тестовом окружении.

**Запрещено:** uninstall, clear-data, factory reset, удаление ключей, смена applicationId или подписи.

Не включать веса Whisper в APK, если существующий механизм использует проверенную отдельно импортированную модель.

## 6. Устранить зависимость от USB-туннеля

Текущая проблема: прямое HTTPS-подключение POCO к AWS через текущую сеть заканчивается тайм-аутом.

USB-туннель работал, но не подходит для автономной Alpha.

Проверить последовательно:

1. Доступность публичного HTTPS endpoint.
2. EC2 Security Groups.
3. IP allowlist и динамические IP клиента.
4. AWS network routing.
5. DNS.
6. TLS certificate и цепочку доверия.
7. IPv4/IPv6.
8. Фильтрацию со стороны используемой сети.
9. Android network configuration.

Определить доказанную первопричину, не подменяя диагностику догадками.

Найти самое быстрое безопасное решение.

Допускается изменение сетевых правил AWS в пределах существующей разрешённой инфраструктуры DORA.

Если для мобильного доступа требуется публичный HTTPS endpoint, обеспечить его защиту с помощью действующего TLS, owner authorization, ограничений API, request limits и существующих security controls.

Не открывать SSH для всех адресов и не отключать авторизацию.

Проверить прямое подключение без USB. При доступности Wi-Fi и мобильного интернета выполнить тесты на обоих каналах.

Если проблема связана с конкретной сетью, установить это отдельными воспроизводимыми проверками.

3. Проверить совпадение подписи и package identity.
4. Открыть исторические записи.
