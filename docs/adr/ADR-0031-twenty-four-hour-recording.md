# ADR-0031 — Twenty-four-hour recording and resumable transcription

Date: 2026-10-30. Authority: the owner's Alpha v9 request and higher-priority 24-hour supplement. This accepts the implementation direction; qualification is determined separately by executed evidence.

The prospective recording limit becomes 86,400 seconds: 1,382,400,000 mono PCM16 frames at 16 kHz, or 2,764,800,000 plaintext audio bytes. Aggregate sizes and offsets use `Long`. Keep five-second encrypted persistence units, ten-minute technical rotation, one logical recording identity and the existing outstanding durability budget. Continue the microphone foreground service across screen-off/background transitions; interruption preserves the committed prefix. Reboot never automatically restarts the microphone. Storage admission uses 200 MB/hour plus a 16 MiB finalization reserve, and warns that a full day needs about 5 GB without reserving it. The initial 125 MB/hour estimate was rejected by the actual API36 full-disk test: each 160,000-byte unit allocated about 236 KiB including directories, keys and manifests. The actual 24-hour allocation and bounded journal growth require separate qualification.

An authenticated source handle verifies the whole source once per attempt. Each range and publication checks live authority, deletion, immutable source metadata and its durable catalog revision; selected ciphertext is authenticated again. A schema-change fence prevents dropping a revision trigger from reviving an old cached snapshot. Handles cannot persist permission across closure or process restart. Metadata indexes and keyset queries prevent repeated full-source scans and repeated prefix traversal during reads, appends and deletion.

Library browsing uses a separate display-only journal projection. It checks current authorization, schema/catalog revision, committed frame and ordering bounds, pending intents, finalization bindings, deletion state and retained source-loss evidence using scalar SQL results and indexed joins. It neither decrypts PCM nor reconciles or repairs a source, and excludes uncommitted reservations from displayed duration. Journal finalization means the recording was durably sealed; the listing does not claim current cryptographic audio integrity and never grants resume or read authority. Explicit recovery, continuation, acquisition and playback retain their existing full authentication contracts. This keeps opening a library independent of total PCM byte volume without persisting an availability capability.

The failed synthetic full-disk attempt also exposed unbounded WAL allocation with automatic checkpointing deliberately disabled. Preserve `synchronous=FULL`, `wal_autocheckpoint=0`, the sole admitted connection and existing driver-policy checks. After a durable commit and its exact readback, an owned operation explicitly checkpoints when the WAL reaches8MiB: require a complete one-row PASSIVE result, then an exact successful TRUNCATE result to release its allocated space. Reject nested transactions and recursive maintenance. A busy, malformed or failed checkpoint fences subsequent writes as uncertain; the already committed prefix remains recoverable. Successful maintenance bounds growth by the trigger plus the largest transaction; no hard bound is claimed after a maintenance failure.

Deletion applies at most256 idempotent effects in one phase, checking live authorization before and after each effect, then commits their exact verified-absence receipts together. Durable completion of all key receipts precedes artifact effects. A crash before the receipt commit leaves pending targets whose already absent keys or files are safely retried. The frozen inventory, per-target bindings, exact receipt readback and final absence checks remain mandatory. Bulk SQL insertion of the frozen inventory and asset-scoped removal of its journal metadata avoid repeated nested per-row Room transactions without changing the deletion phases.

SQLCipher migrates additively from version 4 to 5 for transcript pages, part manifests and audio catalog revisions, then from 5 to 6 for the deletion seek index. Version 5 was installed on a controlled test candidate before the index was added; preserve that migration path and its schema identity. Historical audio and DTR1/DTR2 transcripts remain readable. DTR3 stores a paged reference only when needed. Page edits are revisioned, search streams the selected rendered version, and export reads a stable revision. No operation materializes the complete long transcript. Final machine versions require all parts; completed parts survive cancellation and restart behind an attempt fence.

Local Whisper remains the admitted model and native implementation. Up to 288 contiguous five-minute windows are processed sequentially. No heuristic deduplication may erase legitimately repeated speech. Actual boundary quality and native recognition duration require their own evidence.

Cloud remains disabled for long runs unless a compatible backend advertises the capability. At most 48 balanced children cover the source with no omitted tail. Android upload memory is bounded; backend audio validation and provider upload stream from encrypted storage. A parent reserves the complete first-attempt cost before paid work; retries require additional finite reservation and allocations follow the actual UTC start day. Cancellation durably revokes the parent and all children and erases locally retained results before resumable external cleanup. One first-byte deadline applies across the run. Existing production resources, spending limits and privacy gates are unchanged; a 24-hour run is rejected when the aggregate reserve is unaffordable.

Release evidence must distinguish architecture, physical recording, Local native ASR and Cloud software/live ASR. Synthetic 24-hour encrypted storage is not a physical endurance result. Samsung and POCO installation requires separate owner permission. Full physical 24-hour testing requires the device, power and permission and does not hold up otherwise qualified local Alpha work. Stage12 security/privacy issue 125 remains separate.
