Это окончательная запись причины, а не замена для улучшения результата. В наборе из восьми записей резервов нет: неполный набор блокирует завершение.

Воспроизведение своего голоса для перезаписи

Установите умеренную громкость динамика. Нажмите «Начать запись», затем включите эту собственную READ-запись. Микрофон должен слышать динамик; не используйте наушники. Перезаписывается только ваш разрешённый голос.

3. Человеческий эталон фактической речи

Прослушайте всю запись. Для READ исходный текст уже подставлен: исправьте любые оговорки, пропуски и добавленные слова. Для SPONTANEOUS вручную запишите всё сказанное. Результаты AWS и других ASR не являются эталоном.

4. Фиксация всех восьми записей

Все восемь записей входят в оценку. Резервов и ручной разметки времени нет.

Выберите слово; щёлкните по волне в нужной точке. Нажмите S для начала, E для конца (переход к следующему слову), Пробел для проигрывания. Стрелки ←/→ сдвигают позицию на 10 мс. Никакие отметки не генерируются автоматически.

5. Завершение локальной подготовки

После фиксации набора инструмент проверит корпус, сформирует длинные составные записи и частный манифест. Это не запускает AWS.
